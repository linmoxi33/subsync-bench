工作台说明为什么不是「一条命令」

原工具只做一件事：把字幕平移去匹配视频音轨，然后打印一个偏移量。 它不知道结果对不对，也从不拒绝。这个工作台把整件事包起来： 导入 → 测量 → 对齐 → 预览 → 对比 → 导出， 每一步都能单独复核，最终导出前还会重新测量一遍。

  • 静音参考 原工具返回 0 并写出一个没对齐的文件；这里直接拒绝。
  • 错片字幕 置信度会落到 0.4 以下；这里在 0.55 处拦下。
  • 局部错位 整体平移救不了个别条目；这里逐条标出是哪几条。
  • 导出复检 视频被换过就拒绝导出，而不是信任旧回执。
